## Projetos

### [FinTrackAPI](https://github.com/Iury-Ghub/FinTrackAPI)
API REST multiusuário para gestão de finanças pessoais, evoluída de um protótipo desktop (JavaFX + JDBC) para um backend stateless com Spring Boot. Autenticação JWT com senhas em BCrypt, isolamento de dados por usuário, CRUD de transações e categorias, cálculo de saldo por consulta agregada e tratamento centralizado de erros.

`Java 21` · `Spring Boot 3.2` · `Spring Security` · `JPA/Hibernate` · `PostgreSQL` · `Swagger` · `Docker`

### [Xadrez](https://github.com/Iury-Ghub/Xadrez)
Xadrez para dois jogadores com interface Swing e regras completas da FIDE: roque curto e longo, en passant, promoção, xeque, xeque-mate e afogamento. Nenhum movimento que deixe o próprio rei em xeque é aceito. Inclui histórico em notação algébrica e salvamento de partidas em arquivo.

`Java` · `Swing` · `Maven` · `Arquitetura MVP`

### [gestao-vendas-sql](https://github.com/Iury-Ghub/gestao-vendas-sql)
Sistema de gestão de vendas com modelagem relacional em `schema.sql` e acesso a dados isolado em uma camada de repositório. Conta com testes automatizados e ambiente containerizado.

`Python` · `SQL` · `Docker` · `Testes`

### [automacao-relatorio](https://github.com/Iury-Ghub/automacao-relatorio)
Automação que consolida múltiplos CSVs de vendas em uma base única e gera um relatório gerencial com ranking dos produtos de maior faturamento e crescimento percentual mês a mês.

`Python` · `pandas`

### [Task Tracker CLI](https://github.com/Iury-Ghub/Task_Tracker_CLI)
Gerenciador de tarefas por linha de comando com persistência em JSON via Jackson. Suporta criação, atualização, remoção e filtragem por status.

`Java` · `Jackson`
